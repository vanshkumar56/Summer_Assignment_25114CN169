## 📖 About This Repository

This repository contains my solutions to the **30-Day Summer Vacation Self-Learning Assignment Program** provided by my college.

The challenge consists of **120 coding problems** covering:

* Basic Programming
* Number Theory
* Recursion
* Pattern Printing
* Functions
* Arrays
* Searching & Sorting
* Matrices
* String Manipulation
* Mini Projects

The objective is to strengthen programming fundamentals and develop problem-solving skills through consistent daily practice.
